## 功能

- 手机自适应，页面按屏翻页（scroll-snap）
- WebAudio 实时合成背景音乐与按钮音效，可一键开关
- 一键拨号、导航到店（高德地图）、返回顶部、右侧页码跳转
- 报名表单前端校验 + 成功弹窗，数据写入 localStorage
